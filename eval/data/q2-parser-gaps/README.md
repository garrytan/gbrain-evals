# Q2 parser gaps: development material

Invented development pages for the Q2 parser-gaps harness (gbrain-evals branch `capy/q2-parser-gaps`). They exercise
the junk audit's zero-tolerance classes and the stress-stratum checks on development runs. They are not held-out
material: the custodian's sets N, K, I1, I2, W1, W2 and Q never live in this repository.

- `dev-stress/`: schedules with unfilled slots, glossary and dictionary entries, forms, checklists, changelogs and a
  chat export, plus neighbors that are ordinary typed lines.
- `dev-templates/`: blank meeting, journal and itinerary templates.

All names are generic placeholders (alice-example, acme-example).
