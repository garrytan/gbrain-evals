# Glossary

- [noun] Runbook: a step-by-step guide for an operation
- [verb] Triage: sort incoming issues by urgency
- [informal] Yak shaving: work that is a detour from the goal
- [adj] Idempotent: safe to run more than once
- [Adj.] Stale: no longer current
- [slang] Bikeshed: argue about trivial details
- [archaic] Wherefore: why
- [plural] Indices: more than one index
