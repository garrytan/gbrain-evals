# Ingest disk exhaustion, 2026-05-19

The telemetry ingest host stopped accepting batches with `ENOSPC: no space left on device, write '/var/lib/ingest/spool'`.

Log rotation had been disabled during a migration and never turned back on, so debug logs filled the volume over eleven days. Robots buffered their data locally, so nothing was lost, but dashboards were stale for three hours.

Postmortem written by [[people/june-park]]. Fix: log rotation is part of the host template, and disk usage above 80 percent pages the platform rotation.
