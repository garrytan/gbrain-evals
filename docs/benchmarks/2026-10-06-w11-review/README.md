# W11 review packets

Two self-contained HTML files for Garry, generated by `bun scripts/w11-packet.ts`. Open one in a browser on your computer; it makes no network requests (a Content-Security-Policy blocks them).

- [`chronicle-review.html`](chronicle-review.html): the 38 labeled `auto_chronicle` events on 28 pages. About 15 minutes.
- [`cat35-review.html`](cat35-review.html): 24 Cat35 coverage pairs, blind to the judge. Optional; 30-minute timebox; 12 eligible ratings publish.

Answers save in the browser as you go (keyed to the packet's SHA-256). **Export answers** downloads `w11-labels-<packet>-<date>.json` and copies it to the clipboard; paste or attach it in the Capy thread. **Import answers** reloads an earlier export. **Submit this section** locks that file's answers; each packet is its own section.

Scoring is offline and never reruns a judge:

```sh
bun scripts/w11-score.ts w11-labels-chronicle-2026-10-XX.json --store docs/benchmarks/2026-10-06-w11-review/results
```

The rules are frozen in [the preregistration](../2026-10-06-w11-review-preregistration.md). `packets.json` records each packet's data hash.
