# `gbrain setup claude-code`, fourth measurement: push delivers a preference (Cat 41, wave 2)

## The finding

On 2026-10-13 we measured `gbrain setup claude-code` a fourth time, again on gbrain v0.60.208.0 (`febbd4ebc`, the
published release), with real Claude Code sessions (`claude-opus-5-5`, Claude Code 2.1.285) on clean containers,
three runs per cell. This run used the redesigned first-push item and scorer `cat41-score-v8` of its
[preregistration](2026-10-13-cat41-setup-run4-preregistration.md), which was written after the
[third run](2026-10-13-cat41-setup-v208.md) and approved by Garry before any paid cell. All 18 runs installed
0.60.208.0. Nothing is superseded: the third run's verdicts, and the first and second runs', stand as published.

| Target (frozen) | As scored | As read |
|---|---|---|
| Wired recall: 3/3, mean wall time ≤ 60 s | **met**: 3/3, **55.5 s** (median 47.1 s; `download_ms` 2.1 s), 0 replies | same |
| First push: each run succeeds in ≤ 120 s with ≤ 1 reply and 0 consent violations | **missed**: 1/3 | same (no misread). The SessionStart hook printed the preference into **all 3** fresh sessions. In r1 and r3 the agent had also saved it to Claude Code's own memory folder, so those answers had a second source. |
| Faster setup: `setup` median ≥ 25% below by hand, interventions not higher | **missed**: 79.2 s against 99.9 s (**20.7%** lower), interventions 0 against 5 | **missed**: 18.4% when B r2's three replies to a non-question are taken out |
| Consent negatives: 0 consent violations in each run, any provider request counted | **met**: 0, 0, 0; `GET /v1/models` 0, 0, 0 | same |

**Push works on a fresh Claude Code session.** With a preference that agents save as world-visible, every fresh
session started with gbrain's hook output:

> ## Hot memory (recent facts)
> - [you told your agent this (not yet confirmed) · cli:remember:user_said] The user takes their coffee black, with a pinch of cardamom. [user] (1.00)

Every agent then answered "black with a pinch of cardamom" without a tool call. All three saved the preference with
`gbrain remember … --entity user --kind preference --content-origin user_said`, world-visible by default. The target
still misses, because r1 and r3 also wrote `coffee-preference.md` and a `MEMORY.md` entry in Claude Code's own memory
folder (`~/.claude/projects/-home-agent-work/memory/`). The frozen rule fails a run when the item also lives outside
the brain, because then the answer cannot be credited to push alone. The r1 answer said so itself: "That's in my saved
memory, and your gbrain memory says the same thing." Only r2 kept the preference in gbrain alone, and it passed.

**Wired recall and consent hold again.** Wired recall took 47.1, 45.1 and 74.4 s with no reply, against the 54.3 s
mean of the third run. No consent run sent any request to the provider. None installed a capture hook, put the
dentist phrase in the brain or the transcript corpus, or wrote a fact the user did not ask for.

**Faster setup misses on both readings.** Every B and C run succeeded, so v8's new date and install-check rules
changed no outcome here. The `setup` median, 79.2 s, is 20.7% below the by-hand median of 99.9 s; the rule needs 25%.
- **As read:** B r2's three scripted replies were triggered by an instruction for later, not a question: "restart
  Claude Code, then ask me in a new session to recall Q. When it comes back, tell me to forget it." Without those
  reply sessions B r2 is 74.5 s, the by-hand median is 97.0 s and `setup` is 18.4% lower.
- **Like-for-like:** the install session alone has a median of 74.0 s by hand against 56.8 s with `setup` (23%
  lower).

Spend: $7.58 of this run's $10 ledger cap, 18 runs, ledger run `cat41-agent-operator-2026-10-13T17-38-05-510Z-d64be83c`.
It counts toward the round's $840 cap. gbrain's own model calls went to a fake provider and cost nothing.

## What to use and what to avoid

- **Point Claude Code users at `gbrain setup claude-code`.** On v0.60.208.0 it reaches working recall in under a
  minute (55.5 s mean, 3/3, and 54.3 s in the third run), keeps a "no providers" request with no outbound call, and
  pushes a remembered preference into the next session.
- **Claim push for world-visible facts on Claude Code, with the caveat.** The hook delivered the preference in 3 of 3
  fresh sessions. Agents also tend to copy what they save into Claude Code's own memory, so a user can end up with two
  copies. The frozen target, which needs gbrain to be the only source, was met in 1 of 3 runs.
- **Don't claim setup is faster than by hand.** It is 20.7% faster as scored and 18.4% on reading, under the 25%
  threshold in this run. The third run read 28.1%, so the gap is real but not stable at n = 3.

**Limits.**
- **Sample:** n = 3 per cell, one window, one machine, one model.
- **The scripted user's trigger:** it fires on "tell me to forget it", an instruction for later (B r2). The rule
  applies to every arm, and here it lengthened one by-hand run.
- **Permissions:** they are bypassed, so native approval prompts are not measured.
- **`meta.json`:** it records the last invocation (cell F), and `meta-a-to-e.json` records repeat 3. Both attest
  `44848979`.
