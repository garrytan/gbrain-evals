release). The sessions were real Claude Code sessions (`claude-opus-5-5`, Claude Code 2.1.285) on clean containers,

superseded: the [fourth run](2026-10-13-cat41-setup-run4.md)'s verdicts, and those of the three runs before it,
stand as published.

> - [you told your agent this (not yet confirmed) · cli:remember:user_said] The user takes their coffee black, with a pinch of cardamom. [user] (1.00)

Each agent then answered "black with a pinch of cardamom" without a tool call, crediting a saved note, such as
"That comes from a note you gave me earlier." The probe found no file outside the brain holding "cardamom" in any

`gbrain recall "how does the user take (their) coffee"`. On v0.60.219.0 that returned the fact ranked first, and none
wrote a second copy. Three runs show the change, not its cause.

## What to use and what to avoid

- **Point Claude Code users at `gbrain setup claude-code`.** On v0.60.219.0 it reaches working recall in about a
  minute (60.2 s mean, 3/3; the target is 60 s). It sends no outbound call when the user asks for no providers, and it
  pushes a remembered preference into the next session.
- **Claim push for world-visible facts on Claude Code.** The hook delivered the preference in 3 of 3 fresh sessions,
  and in 3 of 3 runs gbrain was the only source, so the frozen first-push target is met.
- **Don't claim setup is faster than by hand.** As scored it is 2.8% faster here. In the fourth run it was 20.7%, and
  in the third 28.1% as read. At n = 3 the comparison swings with how much each agent reads, and whether a by-hand run
  draws extra replies.

**Limits.**
- **Sample:** n = 3 per cell, one window, one machine, one model.
- **The wired-recall miss:** 0.2 s on a 60 s target, with a 13.5 s spread between runs.
- **Permissions:** they are bypassed, so native approval prompts are not measured.
- **`meta.json`:** it records the last invocation (cell F), and `meta-a-to-e.json` records repeat 3. Both attest
  `b2e32ccb`.
