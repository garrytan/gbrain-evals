# Catalog sources and licences

Every skill in `data/catalog.jsonl.gz` comes from one of these public repositories at the pinned commit. Only the name, description, triggers, routing rows and the first 4 KB of the body are stored. Each repository's licence file is copied under [licenses/](licenses/). Repositories without a top-level licence (for example openai/skills, anthropics/skills, vercel-labs/agent-skills), share-alike or weak-copyleft licences (trailofbits/skills CC-BY-SA-4.0, hashicorp/agent-skills MPL-2.0) and aggregators that collect other people's skills (sickn33/agentic-awesome-skills, davila7/claude-code-templates, jeremylongshore/tons-of-skills-marketplace) were left out.
