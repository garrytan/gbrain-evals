# N2 contradiction judge: every current model passes, and the cheapest costs $0.21 per 1,000 pairs

**Finding.** gbrain's contradiction judge (prompt version 4) passes all of N2's rules with each of the five current models tested, so the failure seen with its default model is specific to Claude Haiku 4.5. On October 6, 2026, replaying the judge's exact inputs from the 2026-10-03 N2 run through gbrain `c5fb0201` (v0.60.95.0), GPT-6 Luna, Claude Sonnet 5.5, GPT-6.1 Sol, Claude Opus 5.5 and Claude Fable 5.1 each **caught all 150 planted conflicts, called none of the 40 dated changes or 251 compatible pairs a contradiction, and raised no false alert on 300 sampled other pairs**. Haiku 4.5, on the same original inputs, called 6 of 51 compatible pairs contradictions (upper 95% bound 24%) and raised 4 false alerts in the same 300-pair sample. The cheapest model that passes is **`gpt-6-luna` at $0.21 per 1,000 judged pairs**, against about $2.50 for Haiku. Passing N2's 10% bar is not the same as being ready to act on verdicts without review: this is one synthetic world, and the result is a component replay of the judge, not a production-path check.

Status: **Complete** (5 of 5 models, 741 of 741 pairs each; 5 transport errors for GPT-6 Luna, 0 for the others). Evidence class: **development evidence**. Preregistration: [2026-10-06-n2-judges-preregistration.md](2026-10-06-n2-judges-preregistration.md), pushed before the first paid call (`dfa2b5b`); the selection file was committed before the first call too (`18b0c68`).

## What N2 measures

[gbrain](https://github.com/garrytan/gbrain) is a memory system for agents. One of its jobs is to notice when two pages in a brain disagree. Its contradiction probe searches the brain with a set of queries, pairs the top results, and asks a chat model, the judge, whether each pair contradicts. A good judge flags "Cormora Example reports $22.5M ARR" against "Cormora Example reports $14.0M ARR" from the same period, but not a change over time ("as of August, headcount is now 346"), and not two compatible statements about the same company. N2 is this repository's benchmark for that: a generated world of fictional companies with 150 planted conflicts, 40 dated changes and 51 compatible negatives offered to the judge, plus 2,439 other pairs the probe happens to offer.

N2's preregistered rules: recall on offered conflicts at least 0.80; false contradictions on dated changes at most 10%; false contradictions on compatible pairs at most 10%. On 2026-10-03, Haiku 4.5 failed the last one (6 of 51, 11.8%).

## The experiment

- **Exact inputs, verified.** The 2026-10-03 receipt stores slugs and verdicts but not the judge's input text. The runner regenerated the N2 world at seed 20261001 and reran the probe hermetically at gbrain `48ed5e8` (that run's build) with a recording judge. All **2,680 of 2,680 (query, page, page) triples matched the receipt**, with the same gold classes and ledger fingerprint (`19459c10…`), before any paid call.
- **Pairs judged, 741 per model.** All 241 planted pairs offered under their own query (150 conflicts, 40 dated changes, 51 compatible pairs, the 51 including 6 namesake pairs); a seeded sample of 300 of the other 2,439 judgments, weighted back to that population; and a fresh split of 200 compatible pairs from the same generator at seeds 20261011 to 20261014, which narrows the decisive bound.
- **Judge.** gbrain's `judgeContradiction` at the round's pin (prompt version 4, the same prompt text as at `48ed5e8`), 1,024-token output limit, provider-default temperature and reasoning. A reply cut at the limit would count as a judge error; none was.
- **Haiku 4.5** is not rerun: its verdicts on the 541 original pairs come from the 2026-10-03 receipt (it has none on the fresh split).

| Claude Sonnet 5.5 | 150 [≥ 97.6%] | 0 [≤ 8.8%] | 0 of 251 [≤ 1.5%] | yes | $4.25 |
| GPT-6.1 Sol | 150 [≥ 97.6%] | 0 [≤ 8.8%] | 0 of 251 [≤ 1.5%] | yes | $2.69 |

The decisive rule is the compatible-pair upper bound: every current model's is 1.5%, far under 10%; Haiku's is 23.9% (it has no fresh-split verdicts, so its bound rests on 51 pairs). Haiku's cost per 1,000 is approximate: its 2026-10-03 run spent $7.04 over 2,774 requests, including a small extra arm.

**False alerts per 1,000 candidate pairs** (at the run's prevalence: 2,680 offered, 150 planted conflicts): **0 for every current model** (0 of 300 sampled other pairs, 0 of 91 planted negatives). Haiku: 4 of the 300 sampled and 6 planted negatives, about 14 per 1,000 (on all 2,439 other pairs it raised 38).

**Paired against Haiku** on the 541 original pairs (a verdict is correct when it calls contradiction exactly on planted conflicts): each current model was right on 11 pairs Haiku got wrong (6 compatible pairs, 1 conflict, 4 sampled pairs) and wrong on none Haiku got right (exact McNemar p = 0.001 each, Holm-adjusted 0.005).

**Adjudication of unplanted alerts.** The union of every model's contradiction alerts on the 300 sampled pairs is 4 pairs, all Haiku's (so hiding which model raised them could not blind anything). All 4 pair a company profile (SAFE cap, runway, headquarters, pilot customers) with a note reporting a different attribute (ARR or headcount): no conflict, so all 4 are false alerts, none ambiguous.

Judge errors: GPT-6 Luna had 5 (0.7%), all on sampled other pairs, from OpenAI server errors after gbrain's three attempts; none affected a planted pair. No model had a truncated reply. The other four models had none.

Wall time per model: 3.6 to 9.4 minutes at 6 concurrent requests (Fable the slowest).

## What to use and what to avoid

- **The N2 compatible-pair failure is a Haiku 4.5 problem, not a prompt problem.** All five current models pass with the same prompt.
- **For gbrain's default contradiction judge, `gpt-6-luna` is the cheapest model that passes**, at about a twelfth of Haiku's cost per pair and with no false alert in this run. Under decision G6, that makes it the candidate for an independent check on gbrain's real production path before any default change. Bigger models bought nothing here: Fable cost 90 times Luna for the same verdicts.
- **Don't treat a pass as permission to act on verdicts unreviewed.** N2's world is synthetic, its conflicts are clean numeric disagreements, and a perfect score on it says little about messy real notes. Keep a human or a second check in the loop for anything that changes pages.
- **Watch for transient errors with Luna.** Its 5 server errors were retried by gbrain and still failed; at production volume, a judge error should leave the pair unflagged and retried later, as gbrain's probe already does.

Limits: one world and seed, single sample per pair, judge-only replay with retrieval fixed from 2026-10-03, and the five models were run at provider defaults (gbrain sets no reasoning effort for OpenAI models).

## Reproduce and inspect

Keyless, $0, from the committed judgments (N2's rules with exact bounds, false alerts, McNemar against Haiku, cost per 1,000, the alert union):

```bash
bun eval/runner/n2-judge-replay.ts score --selection docs/benchmarks/2026-10-06-n2-judges/selection.json \
  --receipt docs/benchmarks/2026-10-03-wave7-repin/n2/receipt-paid-48ed5e8.json docs/benchmarks/2026-10-06-n2-judges/judge-*.json
```

Expected: every current model `passes: true` with 150/150, 0/40, 0/251 and 0/300; Haiku `passes: false` with 6/51; `unplanted_alert_union_in_sample` has 4 ids.

Rebuild the inputs and selection for free (hermetic, no keys; needs a gbrain checkout with commit `48ed5e8`):

```bash
bun eval/runner/n2-judge-replay.ts capture --gbrain <gbrain checkout>@48ed5e8 --seed 20261001 --output capture-20261001.json
bun eval/runner/n2-judge-replay.ts verify --capture capture-20261001.json --receipt docs/benchmarks/2026-10-03-wave7-repin/n2/receipt-paid-48ed5e8.json
# same capture at seeds 20261011..20261016, then:
bun eval/runner/n2-judge-replay.ts select --capture capture-20261001.json capture-2026101{1,2,3,4,5,6}.json --output selection.json
```

Live judge replay, per model (needs the provider key; $0.16 to $14.19 per model in this run):

```bash
bun eval/runner/n2-judge-replay.ts judge --model <provider:model> --selection docs/benchmarks/2026-10-06-n2-judges/selection.json \
  --preregistration docs/benchmarks/2026-10-06-n2-judges-preregistration.md --budget-ledger <ledger> --budget-usd <cap> --output judge.json
```

Spend: $25.52 for the five models (Luna $0.16, Sonnet $3.15, GPT-6.1 Sol $1.99, Opus $6.04, Fable $14.19; one ledger run each), against a $30 estimate and a $38 cap. The input capture, verification and selection cost nothing. Artifacts in [`2026-10-06-n2-judges/`](2026-10-06-n2-judges/): `capture-20261001.json.gz` (every regenerated judge input), `verify-capture.json`, `selection.json` (741 pairs, sha256 `a2f3c276…`), `judge-<model>.json` (every verdict, error, token count and the preregistration attestation), the run logs and `score.json`.
