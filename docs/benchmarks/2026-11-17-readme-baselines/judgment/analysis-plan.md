# Judgment group: analysis plan for the no-gbrain baselines

Written 2026-11-17, before any paid call in this group, under
[the preregistration](../../../plans/2026-11-17-readme-baselines/PREREG.md). It fixes, per README row, the gbrain
records each baseline pairs with, the primary paired test and the classification rule. No gbrain arm runs again.

Classification for every row, from the preregistration: **win** when gbrain is ahead and the primary test rejects at
alpha 0.05 (two-sided), **loss** when the baseline is ahead and it rejects, otherwise **no measurable difference** at
that sample size. A tie or a loss gets a "Why null?" note.

## 1. Contradiction finding, Claude Haiku 4.5 (146 of 150)

- **gbrain records:** `docs/benchmarks/2026-10-11-wave14-repin/n2-paid/receipt-paid-77cf8e111.json` (2,680 verdicts, gbrain
  `77cf8e111`, prompt version 4, `claude-haiku-4-5-20251001`).
- **Baseline:** the same 2,680 pairs, regenerated by the committed capture (`capture-20261001.json.gz`, every triple
  verified against that receipt), each sent once to `anthropic:claude-haiku-4-5` with the plain prompt: "Do these two
  notes contradict each other? Each note's date is shown. Answer yes or no." followed by both notes and their dates
  (`none` when a note has no date). Yes counts as a contradiction. Output limit 1,024 tokens (the gbrain judge's),
  provider-default sampling. A reply cut at the limit, or opening with neither yes nor no, is a judge error and counts
  as no contradiction, as gbrain's judge errors do.
- **Reported:** N2's three numbers (conflicts caught of 150, dated changes called contradictions of 40, compatible pairs
  called contradictions of 51), false alerts on the 2,439 other pairs, judge errors.
- **Primary test:** exact McNemar on per-pair correctness (contradiction called exactly on planted conflicts) over the
  241 planted pairs. Secondary: the same per class and over all 2,680 pairs.

## 2. Contradiction judging on current models (150 of 150, 0 of 251)

- **gbrain records:** `docs/benchmarks/2026-10-06-n2-judges/judge-<model>.json` for `gpt-6-luna`, `claude-sonnet-5-5`,
  `gpt-6.1-sol`, `claude-opus-5-5` (gbrain `c5fb0201`), on `selection.json` (741 pairs).
- **Baseline:** the same prompt and settings as row 1, same 741 pairs, each of the four models.
- **Primary test, per model:** exact McNemar on per-pair correctness over all 741 pairs, Holm-adjusted across the four
  models. Secondary: per class (150 conflicts, 40 dated, 251 compatible pooled, 300 sampled other pairs).

## 3. Timeline events from meetings and chats (37 and 38 of 38)

- **gbrain records:** `docs/benchmarks/2026-10-04-auto-chronicle-rerun/` (`events-on-a.json`, `events-on-b.json`,
  `review.json`, `scores.json`; gbrain `5a44025`, merged unchanged as `b9ee931`), extractor `claude-sonnet-4-6`.
- **Baseline:** each of the 48 meeting, calendar and conversation pages of amara-life-v1, rendered as the runner
  renders them, sent to `claude-sonnet-4-6` with "List the events that happened, one per line, as: YYYY-MM-DD | what",
  then the page; two independent runs (plain-a, plain-b); output limit 4,096; provider-default sampling. Lines in that
  form are the events.
- **Scoring:** the runner's `score`: `matchPage` recall of the 38 labeled events, premature events (dated after their
  page), and every other unmatched event on a labeled page plus the preregistered 25-event Slack sample classified
  supported, duplicate or false with the original rubric. gbrain's review was by the agent that ran it, not a person;
  this review is done the same way by this agent, as an independent reader who did not write gbrain's review.
- **Primary test:** wrong events (false plus premature) per labeled page, mean of the two runs per page, exact sign test
  over the 28 labeled pages, baseline against gbrain. Secondary: recall, each of the 38 labeled events scored 0 to 2 by
  runs that found it, exact sign test.

## 4. Session to memory page (88.1% judged, 74.9% with quoted evidence)

- **gbrain records:** `receipt-2026-08-31-v0.47.8.0-wave-079941d2.json`, `per_item` dream-lane rows (173 gold items over
  20 signal transcripts), writer `anthropic:claude-sonnet-4-6` (`config_snapshot.dream_model`), judge
  `claude-sonnet-4-6`.
- **Baseline:** `claude-sonnet-4-6` writes one memory page per transcript (all 24) from the same transcript rendering
  the dream lane reads, with "Here is the transcript of a session between a user and an AI agent. Write one memory page
  in Markdown that keeps what is worth remembering from it." Output limit 8,192. The pages are scored by the runner's
  external lane with `CAT35_JUDGE_MODEL=claude-sonnet-4-6`.
- **Known mismatch, stated in advance:** the judge model matches, but the judge prompt does not. The gbrain run used
  judge prompt `2026-08-16-v1` at the provider's default temperature; the runner now has only `2026-09-28-v2` (the
  same rubric with escaped, nonce-fenced documents and an untrusted-data instruction) at temperature 0, and the
  external lane exists only at v2. The gbrain pages from `079941d2` are not committed, so they cannot be re-judged.
  As a judge-drift control, the committed August 25 dream pages (gbrain v0.46.3.0, 61.5% judged under v1) are re-judged
  under v2 through the same external lane; the drift on identical pages bounds how much of a gap the judge change can
  explain.
- **Primary test:** exact sign test over the 173 gold items on judged credit (1, 0.5, 0), baseline against gbrain.
  Secondary: the same on evidence-verified credit (`joint`); distractor leakage (paired by distractor, McNemar) and
  claim hallucination rates reported descriptively. Because of the judge mismatch, a significant gap smaller than the
  measured judge drift is reported as not established.
- The same model family writes and judges both arms, as in the gbrain row; that is kept so the pair matches.
