## Preregistration

[`TIME_AWARE_RETRIEVAL_PREREG.md`](https://github.com/garrytan/gbrain/blob/cffbb8ecd3b3377dc0e563c88560e49bab7c8c3e/docs/eval/TIME_AWARE_RETRIEVAL_PREREG.md) fixes the kill gates and the default-on bar before any development run:

- **Kill gates.** A mechanism proceeds only with more paired wins than losses and a paired bootstrap 95% interval above zero on its target. For fact keys the target is NDCG@5 or strict recall_all@5 on LongMemEval-M development questions, and fact keys must also beat the `tokenmax` contextual-synopsis bundle. For time scope it is temporal-reasoning recall@5 where a range fires, with byte-identical rankings elsewhere. For notes-first reading it is judged accuracy through `think`.
- **Default-on bar.** This bar is sealed: LoCoMo, plus the sealed split of LongMemEval-M as disclosed confirmation. It needs a paired interval above zero on the target, no question type down by more than one question, BrainBench and NamedThingBench non-regression, and `think` p95 latency within +20%.
- **Amendment 1** (2026-10-05, before any sealed cell). Embedding and sync cost bounds are reported, not gated. Visibility coverage is reported under both fact-visibility settings. The `tokenmax` comparison runs with production per-chunk synopses. Sealed cells run the frozen build's production fact-key path.

## Development results

Record: [`TIME_AWARE_RETRIEVAL_RESULTS.md`](https://github.com/garrytan/gbrain/blob/cffbb8ecd3b3377dc0e563c88560e49bab7c8c3e/docs/eval/TIME_AWARE_RETRIEVAL_RESULTS.md). Baselines are the release default `balanced`: LongMemEval-S strict R@5 450/470, and LongMemEval-M 367/470.

| Source | Baseline | Arm | Δ (95% CI) |
|---|---:|---:|---:|
| LongMemEval-S `think`, 150 questions (date frame) | 80.7% | 90.0% | +9.3 points [+4.0, +15.3] |
| LoCoMo dev `think`, 3 conversations (date frame) | 76.7% | 89.1% | +12.4 points (3 clusters) |
| LongMemEval-M strict R@5, fact keys from the benchmark prompt | 78.1% | 81.5% | +3.4 points [+1.5, +5.5], 20 wins / 4 losses |
| LongMemEval-M strict R@5, fact keys from gbrain's production extractor (468 questions) | 78.2% | 81.4% | +3.2 points [+1.3, +5.1], 18 wins / 3 losses |
| LongMemEval-S time scope, reserved slots (59 questions with a range) | | | NDCG@5 −0.013 [−0.027, −0.002], 0 wins / 3 losses |
| LongMemEval-S time scope, full partition | | | NDCG@5 −0.101 [−0.150, −0.056], 0 wins / 11 losses |
| LongMemEval-S `think`, notes on vs off | 88.7% | 88.0% | −0.7 points [−3.3, +2.0] |

- **Fact keys.** The production-extractor arm is indistinguishable from the benchmark-prompt arm (−0.2 points [−2.1, +1.7]). Its gains are in temporal reasoning (81 → 86 of 127), multi-session (81 → 86 of 120) and single-session-user (59 → 63 of 64). Page-level keys are rejected, because a shared prefix makes a session's chunks look alike.
- **Time scope.** The parsed range is not selective on these haystacks: 48% of distractor sessions fall inside it, and 39 of 135 gold sessions fall outside it.
- **Deviation.** The `tokenmax` synopsis comparison has not run yet. Amendment 1 adds production synopsis generation to the harness so it runs before any sealed cell.
