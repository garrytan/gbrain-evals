# P2 E2 per-consumer date-grounding checks

(`../2026-10-04-p2-ranking-extraction-preregistration.md`):

- `outputs.ndjson`: 4 prompts × 2 arms × 30 fixtures, generated by `claude-sonnet-5-5` through gbrain's prompt builders;
- `judgments.ndjson`: 1,200 blind pairwise verdicts from `gpt-6-sol`, with A/B order randomized per replicate;
- `report.json`: the summary.

`run.ts` is the script that produced them. It imports gbrain's prompt builders from a gbrain checkout at #6020's head.
`buildSynthesisPrompt` and `atomsPrompt` were exported locally for the run and are unchanged otherwise.
