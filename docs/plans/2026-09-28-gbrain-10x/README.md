# gbrain 10x plan (2026-09-28)

This folder records the plan to make gbrain much better and to make gbrain-evals the evidence that shows it. The maintainer approved it on 2026-09-29.

- [PLAN.md](PLAN.md) is the approved plan. Its "Amendments" section overrides any conflicting text further down.
- [outside-review.md](outside-review.md) is an independent review of the plan by a model from a different family. All ten of its amendments were accepted.
- [audit/](audit/) holds the five audits the plan is based on, run on 2026-09-28: evals correctness, evals docs and infrastructure, capability coverage, the gbrain read path and the gbrain write path.

The audits are dated snapshots, written before the fix wave shipped. gbrain #5666, #5668 and #5676 and gbrain-evals #37 and #38 fix many of their findings.
