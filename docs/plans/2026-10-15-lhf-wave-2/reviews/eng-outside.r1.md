### F1 — SQL cosine needs behavioral equivalence, not just a float tolerance

Item 3 changes more than where arithmetic runs. The existing JS function returns zero for zero norms and dimension mismatches (`src/core/search/hybrid.ts:1636-1647`). Propagating NaN into the blend corrupts scores and sorting; catching a batch dimension error at the existing hydration catch skips rescoring for the entire candidate set instead of assigning that row cosine zero.
