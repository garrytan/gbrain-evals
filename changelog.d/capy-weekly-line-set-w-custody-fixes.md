- Tighter custody for the two sealed world sets, BG1-C and Set W. Template-rendered practice worlds can no longer be validated or pinned as real ones, and practice output can no longer be loaded or pushed to a test machine, outside a keyless test. Sealed renders refuse a set or cache folder inside a git checkout, and a direct real render checks the published seed commitment as the mint does. A mint stops on a skipped slot before it renders past it or reports the set complete. The mint's batch check reads the committed copy of each file. A real mint checks the seed and phrasing against the commitment file the seed check writes, so it renders only from what the launch amendment published ([docs/benchmarks/2026-11-23-weekly-outcome-line-preregistration.md](docs/benchmarks/2026-11-23-weekly-outcome-line-preregistration.md)).
