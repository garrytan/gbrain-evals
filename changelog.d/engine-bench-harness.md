engine-bench, an independent check of whether gbrain's Rust storage engine works like PGLite and Postgres. `eval/runner/eval-engine.ts` opens a gbrain engine of a chosen kind (`pglite`, `postgres` or `rust`) for any runner, and refuses Rust with a stated reason while the gbrain build under test does not carry it. The speed stage (`bun eval/runner/engine-bench/perf.ts`) imports a seeded synthetic corpus through gbrain's own import path with a local seeded embedder and times reads, writes, searches, graph walks, throughput at 1, 4 and 16 clients, cold start, import rate and memory, pairing each query across engines and reading its margins from the preregistration. Every engine-bench stage now runs either as a development run (`--dev`) or as a counted run that needs `--prereg <committed preregistration>`, attests it, refuses a load average above 2 and writes the attestation into its receipt (`eval/runner/engine-bench/counted.ts`). `scripts/ubicloud/engine-bench-setup.sh` prepares a benchmark VM. Tests in `test/eval/eval-engine.test.ts`, `test/eval/engine-bench-perf.test.ts` and `test/eval/engine-bench-counted.test.ts`.
