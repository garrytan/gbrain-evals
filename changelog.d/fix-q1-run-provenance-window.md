- A Q1 cell run is labelled paid only when its lease proxy proves every provider goes to its real host. The proxy's status now reports `paid` beside `keyless`, and a proxy that is neither, such as a stand-in with dummy keys, stops the run before it writes anything. Before, any proxy that was not a recognised rehearsal counted as paid.
- A paid cell run no longer replays reader or judge replies that a keyless rehearsal cached for the same prompts: the shared reply cache keeps each upstream mode in its own folder.
- Every campaign written for one paid window now reserves from that window's ledger, so a fresh campaign counts what the window's other campaigns hold or have settled, and a lease that would pass the window's cap is refused before anything launches.
- `cell.ts merge` reads every unit's receipt before it writes, so a missing receipt refuses cleanly instead of crashing after the run configs are written, and units that ran under different upstream modes (a keyless rehearsal and a paid run) refuse to merge into one score.
