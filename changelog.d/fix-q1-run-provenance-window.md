- A Q1 cell run is labelled paid only when its lease proxy proves every provider goes to its real host. The proxy's status now reports `paid` beside `keyless`, and a proxy that is neither, such as a stand-in with dummy keys, stops the run before it writes anything. Before, any proxy that was not a recognised rehearsal counted as paid.
- A paid cell run no longer reuses reader or judge replies, or the plain hybrid baseline's embeddings, that a keyless rehearsal cached for the same input. The shared caches keep each upstream mode in its own folder, so replies and embeddings cached before this change at the old top level aren't read again.
- Every campaign written for one paid window now reserves from that window's ledger, whose cap is the window's cap minus what the window's mint, re-read and labelling commands may spend. A fresh campaign counts what the window's other campaigns hold or have settled, and a lease that would pass the cap is refused before anything launches. The ledger lives in the checkout, so every campaign of a window starts from one checkout, and a window name can't be reused for a grant with a different cap.
- `cell.ts merge` reads every unit's receipt before it writes, so a missing receipt refuses cleanly instead of crashing after the run configs are written. Units that ran under different upstream modes (a keyless rehearsal, a paid run, or a unit with no upstream record) refuse to merge into one score.
