- **N14 large-page fidelity now scores keyword recall on the Rust engine.** `eval/runner/n14-large-page-fidelity.ts` mapped each search hit to its stored passage with a raw SQL read of `content_chunks`, which the Rust engine refuses, so every Rust hit scored as a miss and recall was reported as not applicable. The runner now reads the passage by chunk id through the engine's own chunk reads on every engine, so recall@10 and the delivered and distractor ranks are measured on Rust too, and the solvability control is reported there, though it still stops the run only on PGLite and Postgres. On PGLite and Postgres the passages are the same rows the raw SQL read, on an inline page and on a segmented page after an append, which new keyless tests check. The Rust N14 verdict is unchanged: it is still the safety contracts and the stored page, as the engine-bench preregistration's 2026-11-20 amendment sets.
