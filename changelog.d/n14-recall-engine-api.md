- **N14 large-page fidelity now scores keyword recall on the Rust engine.** `eval/runner/n14-large-page-fidelity.ts` mapped each search hit to its stored passage with a raw SQL read of `content_chunks`, which the Rust engine refuses, so every Rust hit scored as a miss and recall was reported as not applicable. The runner now reads the passage through the engine's `getChunkPage` on every engine, so recall@10, the delivered and distractor ranks and the solvability control are measured on Rust too. On PGLite and Postgres the passages are the same rows the raw SQL read, which a new keyless test checks. The Rust N14 verdict is unchanged: it is still the safety contracts and the stored page, as the engine-bench preregistration's 2026-11-20 amendment sets.
