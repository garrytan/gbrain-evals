CI no longer fails a check when the cache service that holds the git history hangs. Each restore step stops after 2 minutes, drops what it had restored and lets the job check out from GitHub instead, and the two shortest jobs now have 10 minutes so that checkout still fits. On a pull request a hung lookup no longer starts a rebuild of the cache, and saving the cache stops after 5 minutes without failing the run. A hung cache had turned main and pull requests red on 2026-11-23 without any test failing.
