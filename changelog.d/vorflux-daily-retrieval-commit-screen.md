- **You can now screen a day's commits for ones that may move a retrieval benchmark.** `scripts/retrieval-commit-screen.ts` reads your local git checkout of gbrain or gbrain-evals and tags every commit in a time window `yes`, `maybe` or `no`, with the reason, so you can tell which engine-bench or retrieval baselines need a rerun. It makes no network calls and changes nothing. [How to run it and read the tags](scripts/retrieval-commit-screen.md).
